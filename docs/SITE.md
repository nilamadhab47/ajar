# Ajar — Marketing Site (meetajar.com)

> The landing page lives in the same Next.js app as the office, but apart from it: its own route group, its own
> folder (`src/site`), its own styles and fonts, and no app stores. Brand and voice: [BRAND.md](BRAND.md).

## 1. Routes

| Route | What it is |
|---|---|
| `/` | The landing page (`src/app/(site)/page.tsx`). It used to redirect to the office. |
| `/demo` | Redirects to `/login`. "Walk into Ajar" goes to sign-in. |
| `/workspace/...` | The app. Unchanged. |
| `/sitemap.xml`, `/robots.txt` | Generated by `src/app/sitemap.ts` and `robots.ts` (the app routes are disallowed). |

## 2. Where things live

```
src/app/(site)/layout.tsx     metadata, Open Graph, viewport, fonts, .site-root wrapper
src/app/(site)/page.tsx       section order + JSON-LD
src/site/config.ts            SITE (url, title, description, earlyAccessUrl, social), nav links, sprite tables
src/site/site.css             every site style, scoped under .site-root
src/site/fonts.ts + fonts/    self-hosted Fraunces, DM Sans, Press Start 2P (OFL licences alongside)
src/site/components/          Logo (vector door mark), SiteNav + SoundToggle, Pixel (Sprite, OfficeCrop, at()), Reveal, AvatarShuffle
src/site/sections/            DoorHero, WorkingApart, LivingWorld, Knock, DeskDrops, Clocks, Yours, Invitation (+ footer)
src/site/game/                MiniOffice.tsx (React host), mini-office.ts (Phaser scene), mini-types.ts (shared, no Phaser)
src/site/lib/                 analytics.ts, sound.ts, scene.ts (scripted GSAP scenes), hooks.ts
scripts/build-site-assets.ts  bakes the Imersa pack (beside the repository) into public/assets/imersa
public/assets/audio/          sound files (silent placeholders) + README
public/og.png                 social preview image
```

Changes outside those folders: `src/app/globals.css` gained the site colour and font tokens and one rule that
lets marketing pages scroll (`body:has(.site-root)`); `src/app/page.tsx` moved into the route group;
`package.json` gained `gsap` and the `site-assets` script.

## 3. Design system

| Token | Hex | Tailwind |
|---|---|---|
| Ajar Purple | `#6C63C7` | (app `accent`) |
| Lamp Light | `#F4C36B` | `lamp` |
| Deep Aubergine | `#21172F` | `aubergine` |
| Warm Ivory | `#F7F3EC` | `ivory` |
| Soft Lavender | `#E9E4F5` | `mist` |
| Evening Grey | `#777481` | `evening` |
| Ink | `#292630` | `night` |
| Soft Sage | `#C7D8C0` | `softsage` |

- **Lamp Light keeps its meaning:** an approachable person, an open door, a welcoming action (primary buttons,
  lit lanterns, sticky notes). Don't use it as decoration.
- **Type:** Fraunces (`font-display`, `.display`, italic lamp-coloured `<em>` for the emphasised phrase),
  DM Sans (`font-site`), Press Start 2P (`font-pixel`, `.pixel-label`) only for labels inside the pixel world.
  Sizes are fluid: `.h-hero` 46–112px, `.h-section` 36–72px, `.lede` 17–20px.
- **The one visual rule:** outside the door is flat and editorial; inside the door is pixel art. The hero's
  threshold is where the style changes, and every later section is one or the other.
- **Layout:** max content width 1320px, 8px spacing rhythm, sections alternate aubergine / ivory / lavender.
- **Motion:** slow and soft. No bounce. Everything respects `prefers-reduced-motion`.

## 4. Asset manifest

| Asset | Source | Notes |
|---|---|---|
| `public/assets/imersa/office-base.png`, `office-props.png`, `office.json` | Baked from the pack's `Office_Showcase` room | Floor and walls, props atlas, positions, 16px collision grid. Used by the playable scene. |
| `public/assets/imersa/office-full.png`, `@2x` | Same | The composed still used by the hero and the editorial crops. |
| `public/assets/imersa/characters.png`, `@3x` | The pack's five characters | One sheet, 4 frames × 8 rows each. |
| Door, sconce, plant, logo, "working apart" illustrations | Original, drawn in SVG/CSS in the components | No raster files. |
| Avatar in "Make it yours" | The app's own compositor (`AvatarPreview`) | Real product code, loaded lazily. |

**The Imersa pack is never modified and never committed.** `npm run site-assets` reads
`Office_Pixel_Art_Premium_v1.0/` from the folder next to this repository (or from `AJAR_ART_PACK`) and writes
colour-graded copies to `public/assets/imersa/` (git-ignored). The grade is a split tone (aubergine shadows,
warm highlights) plus baked lamp pools; the licence allows recolouring. **Those baked files must exist when
the site is built for deployment** (see §8).
Characters only have idle and walk animations, so nobody sits: people stand at their desks.

## 5. Motion storyboard

**Hero (`DoorHero`)** — one sticky stage, 330vh of scroll (250vh on phones). Scroll progress `p` (0→1) drives
CSS variables on the stage; scrolling back reverses it exactly.

| p | What happens |
|---|---|
| 0 | Aubergine wall, door ajar 17°, golden haze in the gap, light on the floor, headline and buttons. |
| 0–0.4 | The door swings in to 100°. Haze thins and the pixel office shows through. |
| 0.05–0.24 | Headline and buttons fade up and out. |
| 0.3–0.86 | The hole in the wall grows past the screen edges (four flat wall panels around a rectangle, not a scaled layer). The office eases from 1.22× to 1× and recentres. Sconce and plant fade. |
| 0.45–0.7 | Characters fade in and walk. |
| 0.86–0.96 | "You're in" card appears. |

Reduced motion: no pinning, a still of the open doorway. Keyboard: the first Tab stop is "Skip the intro and go
to the office".

**Scripted scenes (`useScene` in `lib/scene.ts`)** — GSAP timelines that loop only while on screen:
knock (walk up → prompt → knock rings → "…" → "Come on in." → two lines of chat) and desk drops (leave a note →
night → morning → a colleague reads it and replies). Under reduced motion they rest on their final frame.

**Clocks** — no animation: four desks tinted by each city's real current hour, updated every 20 seconds.

## 6. The playable office

`MiniOffice.tsx` boots Phaser only when the section is within 500px of the viewport and pauses the loop when it
scrolls away. The scene (`mini-office.ts`) is separate from the app's `OfficeScene`: no stores, no realtime
adapter. It reuses the app's `NavGrid` and A* (`findPath`).

- Walk: arrow keys / WASD while the office has focus (Esc gives the keyboard back), click or tap a spot, a
  touch pad on touch devices, or the room buttons under it.
- People in the illustration: Prayag, Engineering (door open, knock accepted at once), Yuri, CTO (ask first, decides after a
  moment), Steye, CEO (door closed, offers a note), Zenno, COO's empty desk (leave a note, then skip to the morning).
- **Nothing here connects audio or video, and the UI says so.** Conversations are short scripted text.
- React owns every HTML control; the Phaser game sits in a ref. Events flow through `MiniEvent` / `MiniOfficeApi`.

## 7. Sound and analytics

- **Sound** is off by default and never plays before the visitor presses the speaker button. Files and their
  briefs: `public/assets/audio/README.md`. Register or rebalance sounds in `SOUNDS` (`src/site/lib/sound.ts`).
- **Analytics:** `track(event, props)` pushes to `window.dataLayer` and fires an `ajar:track` DOM event. Nothing
  is sent anywhere until a provider is attached. Events: `hero_door_opened`, `hero_skip`, `cta_click`,
  `office_started`, `office_room`, `office_knock`, `office_note`, `office_fast_forward`, `office_reset`,
  `sound_toggle`, `avatar_shuffle`.

## 8. Before launch

1. **Deploy with the baked art.** `public/assets/imersa/` is git-ignored because the repository is public and
   the pack's licence forbids redistributing the files. Run `npm run site-assets` and deploy from a machine
   that has them (for example a prebuilt deploy), or make the repository private and commit them.
2. Replace the silent audio placeholders.
3. Set `SITE.earlyAccessUrl` (a form or mailto) to show "Request early access", and `SITE.social` for footer
   links. Add privacy and terms pages before collecting any sign-ups.
4. Attach an analytics provider to the `ajar:track` event.
5. Test on real phones and a low-end laptop; only headless Chromium has been used so far.

## 9. Rules

- Don't present the landing office as real multiplayer or real audio.
- Every visible button works. A destination that doesn't exist yet is left out, not faked.
- Site code doesn't import app stores; app code doesn't import from `src/site`.
- Keep the page quiet: one idea per section, no scroll-jacking beyond the hero, sound opt-in.
